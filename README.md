# Glimmer — Instagram

Materiale pentru promovarea brandului Glimmer (Cosmetic Shop, Moldova) pe Instagram.

- `posts/CAPTIONS.md` — textele postărilor
- `posts/<postare>/*.jpg` — imagini 1080×1350 (4:5)
- `assets/products/` — fotografii produse, doar de pe cosmeticshop.md/glimmer (vezi `RULES.md`)
- `scripts/make_posts.py` — regenerează imaginile: `python3 scripts/make_posts.py`
